# Abhay Vishwakarma — Graphic Design Portfolio

A responsive, multi-section portfolio website built with plain HTML, CSS and JavaScript. No build tools or package installation are required.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For a local development server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## What's included
- Personal hero section using the supplied portrait image
- Selected work gallery with category filters and project-detail modals
- Brand identity, UI/UX, social media, advertising, print, editorial, packaging, illustration and motion design disciplines
- About, process, expertise and contact sections
- Responsive desktop, tablet and mobile layouts
- Keyboard-accessible modal close behavior and reduced-motion support

## Personalise before publishing
- The contact section visibly displays `hello@abhaydesigns.in`; clicking it opens an email addressed to `vishwakabhay005@gmail.com`.
- This is a static portfolio website and does not contain a server-side backend or contact-form processing. The email link uses the visitor's configured mail application.
- Social-profile placeholder links have been removed.
- Replace the fictional concept projects with your actual work, process images and outcomes. They are explicitly identified as concept explorations and should not be represented as client commissions.
- Add real project images/mockups to `assets/` and update the artwork blocks in `index.html` as desired.
- Update the page title, description, availability and biography to match your current details.
